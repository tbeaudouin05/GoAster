# Authorization

Bitwarden Secrets Manager setup and secret migration are consequential credential changes. Explain the steps first and obtain explicit user approval before creating machine-account access, writing secrets, switching GoAster away from server-local env, or deleting the local copy.

Never request, print, log, commit, or send a machine-account access token through ordinary chat. Accept it only through the approved secure setup path, keep it out of model-visible output, and report metadata only.

Use Bitwarden Secrets Manager only. Do not substitute a secure note, personal-vault item, master password, or long-lived Bitwarden CLI session.
