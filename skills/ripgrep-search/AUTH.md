# Authorization

Searching local files is read-only. Check whether `rg` is already installed before recommending installation.

Installing software changes the host. Explain the package-manager command and obtain explicit approval before installing ripgrep, unless the user has already explicitly authorized installation as part of the current task.

Use the host's official package manager only. Do not pipe downloaded shell scripts into a shell, add an unverified repository, change unrelated packages, or use elevated privileges without the user's approval.
