# GoAster Telegram Groups Best Practices

A good way to use GoAster is to create a separate Telegram group for each task or project. Each group provides an independent conversation with GoAster. Explain how to set this up manually:

1. Create a Telegram group for the task or project.
2. Add your GoAster bot to the group.
3. Open `@BotFather`, send `/setprivacy`, select your bot, and choose **Turn off**.
4. If the bot was already in the group when you changed this setting, remove it and add it again.
5. Send a message in the group. You can speak to GoAster normally without tagging the bot.

The user performs these steps themselves. Do not attempt to change BotFather settings or group membership on their behalf.
