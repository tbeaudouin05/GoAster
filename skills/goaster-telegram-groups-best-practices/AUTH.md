# Authentication

This skill provides manual Telegram group setup guidance. The user performs
the steps themselves; this workflow does not authenticate to Telegram or
change BotFather settings or group membership on the user's behalf.

The Telegram bot token is the bot's authentication credential. Obtain and use
it only through the approved protected local setup workflow. Never ask the user
to paste it into chat, reveal, quote, log, screen-capture, put it in a command
argument, or include it in a report or repository file. If it is exposed, stop
and tell the user to revoke or regenerate it with BotFather; do not repeat it.
Keep pairing details out of chat, command arguments, logs, reports, and
repository files as well.
