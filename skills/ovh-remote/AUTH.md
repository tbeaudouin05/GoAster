# Authorization

Confirm the exact target. For the exact instance created and verified in the same provisioning flow, automatically record its host key on the first SSH contact in a unique target-specific `known_hosts` file using `StrictHostKeyChecking=accept-new`; use that file with `StrictHostKeyChecking=yes` for all later connections. Never ask the user to retrieve, compare, approve, or paste its SSH host-key fingerprint. For pre-existing or provenance-unclear hosts, require an already trusted entry or trusted-channel fingerprint verification and approval before connecting. Get explicit approval for the target-specific routine checklist and separately gated changes. Keep secrets out of chat and shell output; use the protected profile-based process handoff.
