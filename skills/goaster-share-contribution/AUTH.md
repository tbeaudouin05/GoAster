# Authentication

Load [github-auth authentication guidance](../github-auth/AUTH.md) before any
GitHub access. When fork or source setup applies, use the authenticated
handoffs from [goaster-fork](../goaster-fork/AUTH.md) or
[modify-goaster-source-code](../modify-goaster-source-code/AUTH.md). Recheck the
authenticated account and exact destination before each GitHub write, and keep
credentials and device information in the local authentication flow.
